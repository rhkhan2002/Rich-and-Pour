Hosting & Setup Guide

Answers to hosting questions for student-run coffee shops.

Q1

Can this app be hosted directly from Google Drive?

Short Answer: No longer officially supported directly by Google, but there are free alternatives.

In the past, Google Drive permitted web pages to be served publicly via direct HTML URLs. However, Google officially deprecated drive-hosted website rendering for security and platform performance reasons.

Recommended Free Modern Hosting Alternatives:

  • GitHub Pages (Recommended): Completely free. Upload this single index.html file to a public GitHub repository and enable Pages for a custom, permanent web link.
  • Netlify or Vercel: Drag and drop this HTML file onto their web dashboards to receive an instant, free HTTPS link (e.g., https://campus-brew.netlify.app).
  • Google Cloud Storage / AppSheet: If your university requires staying strictly within Google Workspace, you can host static files via Google Cloud Bucket or convert the workflow to a Google AppSheet app.
Q2

Can we use Google Forms & Google Sheets for this loyalty program?

Short Answer: Yes! A Form + Sheet + Google Apps Script setup is a popular, low-tech option.

If your student team prefers to manage everything inside Google Sheets, here is the exact step-by-step workflow:

Step 1: The Form Create a Barista Google Form with 2 fields:
  • Student ID / Email
  • Number of Drinks Purchased
Step 2: Google Sheet Formula Link the form to a Sheet. Calculate total credits with standard formulas:
=SUMIF(Responses!A:A, ID, Responses!B:B)
Add logic for Tuesday double points (IF(TEXT(Date,"dddd")="Tuesday", Drinks*2, Drinks)).
Step 3: Apps Script Emailer Write an Apps Script (Tools > Apps Script) that automatically emails the student when their credit total hits a multiple of 10!
Sample Apps Script Code Snippet for Sheet Auto-Emailer: 
function checkLoyaltyRewards(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var lastRow = sheet.getLastRow();
  var studentEmail = sheet.getRange(lastRow, 2).getValue();
  var totalCredits = sheet.getRange(lastRow, 4).getValue(); // Calculated column
  
  if (totalCredits >= 10 && totalCredits % 10 === 0) {
    MailApp.sendEmail(
      studentEmail, 
      "☕ Free Drink Earned at Campus Brew!", 
      "Congrats! You've reached " + totalCredits + " credits. Show this email to claim your free drink!"
    );
  }
}
